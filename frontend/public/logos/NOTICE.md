# Provider marks — what these are and where they came from

*This file is published alongside the images it describes, at
`/logos/NOTICE.md`, because a record nobody can read is not a record.*

These are **third-party trademarks**, shipped so that somebody naming a connection
can put their provider's own mark on it. Using a mark to identify that vendor's
product is ordinary nominative use, and it is the only use memex makes of them:
they are offered in the icon picker, and nothing else in the product displays one
unless a person has chosen it.

They are **not** endorsements, and no vendor here has any relationship with
memex.tools.

## The rules this set follows

- **One file when the mark has real colour**, because a coloured mark reads on a
  light background and a dark one alike. **Two files when it is monochrome by
  design** — `-on-light` for a light background, `-on-dark` for a dark one —
  because a black rosette is invisible in dark mode and so is a white one in
  light mode.
- **Nothing is redrawn from memory.** Every file below came from the source
  named in its row. Where a variant had to be produced, the change is mechanical
  and is stated exactly, so it can be checked against the original.
- **Cleaning applied to every SVG:** the XML declaration, any DOCTYPE, comments,
  and any off-canvas `<text>` element left behind by the exporter are removed.
  No path data, no colour and no viewBox is touched.
- **Nothing is scaled or cropped.** Aspect ratios vary; the picker fits rather
  than crops, which is the same rule uploaded icons follow.

## Where they came from

Supplied on **2026-08-23**, sourced from **zonalogo.com** except where the row
says otherwise. These are that site's renderings of each mark rather than
files taken from each vendor's own brand kit — a real difference, recorded here
rather than glossed. **If a vendor's official file is ever obtained, it should
replace the row below rather than be added beside it.**

## Requests

If you own one of these marks and would rather it were not shipped, or would
prefer a different file be used: hello@memex.tools. It will be removed or
replaced.
