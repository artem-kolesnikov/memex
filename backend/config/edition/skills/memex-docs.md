memex's documentation is at https://docs.memex.tools. The pages describe memex.tools; where self-hosted memex differs, a page says so in a **Self-hosted memex** note, and the [Self-hosted memex](https://docs.memex.tools/self-hosted) pages cover the rest.

Every page is also Markdown at its address ending in `.md`: https://docs.memex.tools/llms.txt lists them all, and https://docs.memex.tools/llms-full.txt holds every page in one file. Link people to the page, without `.md`.
